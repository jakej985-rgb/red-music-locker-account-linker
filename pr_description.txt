💡 What: The UX enhancement added:
Added `aria-live="polite"` and `role="status"` to the dynamic status message element to make it visible to screen readers. Added `:focus-visible` styling to both the inputs and buttons to show a high contrast ring, making it easier to know what is currently focused for keyboard navigators. Added `required`, `spellcheck="false"`, and `autocomplete="url"` to the URL input for standard browser URL field improvements.

🎯 Why: The user problem it solves:
The default focus ring on browsers varies and sometimes doesn't stand out strongly against dark mode extension themes, hurting keyboard accessibility. Screen readers would also fail to notify the user of background-auth status update messages generated by `popup.js` because the container element lacked ARIA live region attributes.

📸 Before/After: Screenshots if visual change:
Added clear high-contrast focus rings when elements are focused.

♿ Accessibility: Any a11y improvements made:
Significantly improves keyboard accessibility via custom focus-visible ring styles. Screen readers will now automatically announce live connection feedback to users (e.g. error/success status output) via the injected ARIA attributes. Also properly scopes the URL input.
